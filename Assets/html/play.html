Challenge #21

Write a function that transforms input data into a normalized list.

Time: 03:12
Tests running

Instructions

You are given an array of objects. Return a new array containing only entries that match the rules, and map them into a simpler shape.

  • Keep order stable
  • Remove invalid entries
  • Return normalized values
Use the hints on the right when you get stuck.
solution.js
// Normalize input data
function normalize(items) {
  const out = [];
  for (let i = 0; i < items.length; i++) {
    const it = items[i];
    if (!it || it.isValid !== true) continue;

    out.push({ id: it.id, name: String(it.name).trim() });
  }
  return out;
}
